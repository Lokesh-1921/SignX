# SignBridge-Dialect

SignBridge-Dialect is a future consent-first research dataset, not a pre-existing asset. Each sample requires a participant-consented video, signer pseudonym, documented region/language context if the participant chooses to provide it, style, source/annotation provenance, context fields, annotator/version, and deletion mechanism.

Regional meaning annotations require human annotation and documented sources. The system must never infer, invent, or normalize away a regional/informal sign meaning. Contributors must be able to request deletion, and private videos must not be published or bundled in model artifacts without specific permission.
