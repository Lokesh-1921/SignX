# Changelog

All notable changes to SignBridge are documented here.

## [0.1.0] - 2026-08-22

### Added

- Repository foundation, Python environment contract, and data safety rules.
- Universal manifest schema and signer-independent split utility.
- Lazy video/NumPy loader, temporal sampler, and landmark cache contract.
- Configurable RGB/pose temporal-transformer baseline.
- Training, checkpoints, JSONL experiment tracking, metrics, and validation.
- Synthetic end-to-end smoke test and unit-test suite.

### Not included

- Public datasets, recorded metrics, regional-sign interpretations, or trained research models.
